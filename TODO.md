# DevIA — critérios do scaffold

- [x] Dashboard SaaS moderno, premium e responsivo, com estética tecnológica elegante e minimalista: fundo escuro/grafite, detalhes em azul/roxo/verde, cards modernos, bordas discretas, boa hierarquia visual, aparência profissional de ferramenta de desenvolvimento, excelente experiência desktop e responsividade básica para mobile.
- [x] Sidebar com navegação funcional para Projetos, Conversas, Preview, GitHub, Supabase e Configurações.
- [x] Dashboard com projeto atual, status do projeto, estados GitHub e Supabase desconectados, último trabalho realizado e botões “Abrir projeto” e “Novo projeto”.
- [x] Conversas preparadas para futura IA, sem agente real: histórico de mensagens demonstrativas, campo de comando, botão enviar, indicador demonstrativo de processamento e área de ações realizadas pela IA.
- [x] Preview do projeto com barra superior, URL fictícia, ação atualizar, ação abrir em nova aba e visualização central demonstrativa.
- [x] Painel de arquivos demonstrativos `src/pages/Login.tsx`, `src/components/Button.tsx` e `src/styles/global.css`, com ações visuais “Ver alterações” e “Desfazer”, sem Git diff real ou alteração de arquivos.
- [x] GitHub: página com a mensagem “Conecte seu repositório para permitir que a plataforma trabalhe sobre o seu código.” e botão “Conectar GitHub”; sem OAuth complexo e preparado para GitHub App/OAuth futuro.
- [x] Supabase: página com a mensagem “Conecte seu projeto Supabase para permitir futuramente que a IA trabalhe com banco de dados, tabelas, migrations e políticas.” e botão “Conectar Supabase”; sem integração real.
- [x] Projetos com nome, status, repositório, última atualização e botão abrir; dados demonstrativos.
- [x] Configurações como placeholder funcional.
- [x] Arquitetura modular separando páginas, componentes, layout, serviços, tipos, integrações, estado e configuração, preparando pontos para GitHub, Supabase, Gemini, OpenAI, outros modelos, sandbox de execução, preview, deploy e agentes futuros.
- [x] Aplicação pequena e navegável, sem dependências desnecessárias, backend complexo, pagamentos, afiliados, agentes autônomos, múltiplos modelos, deploy automático ou sandbox completo.
- [x] Prioridades preservadas: interface profissional, código limpo, componentes reutilizáveis, navegação funcional, extensibilidade e facilidade de leitura/modificação futura por IA.
